# Contributing to Vet Anesthesia Monitor

First off, thank you for considering contributing to this project! It's people like you that make the open-source community such a great place to learn, inspire, and create.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check the [Issues](#) tab first. If you don't see it there, feel free to open a new one.

## How to Contribute

### 1. Fork the Project
Fork the repository on GitHub to your own account.

### 2. Create a Branch
```bash
git checkout -b feature/AmazingFeature
```

### 3. Make your Changes
Ensure you follow the existing code style. The project uses vanilla JS and CSS, bundled via Vite.
If you're adding UI components or modifying styles, please ensure they remain highly responsive for mobile/tablet environments.

### 4. Test
Run the test suites locally to ensure you haven't broken anything:
```bash
# Unit tests
npm run test:unit

# End-to-end tests
npm run test:e2e
```

### 5. Commit & Push
```bash
git commit -m 'Add some AmazingFeature'
git push origin feature/AmazingFeature
```

### 6. Open a Pull Request
Go to the original repository and open a Pull Request. Please provide a clear description of your changes and the problem they solve.

## Setting up your local environment
Please refer to the `README.md` for standard installation instructions. You will need your own Firebase backend and Gemini API key to develop successfully.
